Quality Gate Keaslian Video: Real Try-On vs AI Bot

Aturan Mutlak Monture: Sampel fisik hanya diberikan kepada creator manusia nyata yang mencoba produk

👤
Karakteristik Real Human Try-On (LOLOS)
Kreator dengan potensi konversi penjualan tertinggi
  • ✓
    Fisik Orang Terlihat Nyata: Kreator memakai rompi/jaket secara langsung di depan kamera (*fitting on body*).
  • ✓
    Ulasan Detail Bahan & Fitting: Menunjukkan tekstur kain puffer, kerapian jahitan, kantong, dan resleting.
  • ✓
    Audio Alami & Suara Asli: Narasi berbicara asli manusia (bukan suara template robot TTS kaku).
  • ✓
    Interaksi Komentar Ukuran: Ada tanya jawab ukuran badan (*"TB 170 BB 65 ambil size L kak"*).
🤖
Indikator AI Generator / Bot (GUGUR OTOMATIS)
Akun berisiko tinggi pemborosan HPP produk toko
  • ✗
    Slideshow Foto Katalog: Hanya kumpulan foto katalog toko yang digeser dengan efek musik CapCut tanpa orang memegang barang.
  • ✗
    Avatar Tiruan AI (Deepfake): Model animasi digital dengan gerakan bibir kaku dan tekstur kulit plastik sintetis.
  • ✗
    Reupload Video Luar Negeri: Mengambil video promosi model luar negeri yang tidak sesuai dengan produk fisik Monture.
  • ✗
    Anomali Engagement: Ribuan views tanpa interaksi like atau komentar sama sekali (indikasi bot trafik palsu).

Inovasi Teknis: Ingestion & WAF Bypass Otomatis

Bagaimana dashboard berhasil menarik 514 data TikTok secara instan tanpa kendala blokir keamanan

1
Tantangan WAF
Proteksi Bot TikTok

TikTok menerapkan signature kriptografis X-Bogus dan msToken yang otomatis kadaluarsa dalam waktu ~60 detik dan menolak request otomatis dari server luar.

2
Solusi Console Ingestion
Memanfaatkan Browser Asli

Script otomatis dijalankan langsung di tab browser yang sudah login. Browser sendiri yang men-generate signature secara legal untuk memutar seluruh halaman 1 hingga 11 dalam 10 detik.

3
Dual-Mode Importer
100% Bebas Kadaluarsa

Modal di Monture Dashboard mendukung impor langsung via Response JSON atau cURL Parser dengan deduplikasi otomatis berdasarkan apply_id.

Logika Loop Aman Penarikan 514 Data di Browser:

// Alur Looping Otomatis (Page 1 sampai Page 11) dengan Safety Delay 600ms: for (let page = 1; page <= totalPages; page++) { const data = await fetch('/api/v1/affiliate/sample/group/list?...', { cur_page: page, page_size: 50 }); allSamples.push(...data.agg_info); await sleep(600); // Mencegah pemicu rate limit WAF TikTok } copy(JSON.stringify(allSamples)); // Otomatis disalin ke Clipboard Windows!
